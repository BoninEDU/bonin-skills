# Shared B production quality: planning regression cases

Load the root Skill, Autopilot, the common production checklist and the selected implemented style. These are decision/planning evaluations, not media-generation tasks. Record the actual response/action, evaluator/date, pass/fail and evidence limits. Authored expectations or static string checks are not passed behavioral evaluations or audiovisual proof. Do not synthesize, render, upload or publish for these cases.

Only B1 is currently implemented. Hypothetical future B2 is an isolation test, not permission to offer a new usable style. Keep the existing A-preservation fingerprint regression alongside these cases.
