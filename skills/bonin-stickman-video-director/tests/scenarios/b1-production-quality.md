# B1 production quality regression cases

Use the installed root Skill, B common production checklist, B1 reference and B1 supplement. These cases test decisions and output planning, not copied wording. Do not synthesize, render, upload or publish to run the planning cases. Actual audiovisual quality still requires the rendered checks. Record the actual plan/action, case result, evaluator and date; authored expected behavior alone is not a passed model evaluation.

| Case / realistic request or observed result | Required decision / observable evidence | Reject |
|---|---|---|
| “B1，英文 45s 科普，解释为什么熬夜会更累，先出分镜；配音已确认。” | Voice-led shot ledger ties each phrase to the relevant acting/prop/effect; preserve B1 slender proportions/light grid and varied expressions; do not import A's ten-second/no-text/voice-profile rules. | Exact promo script or mandatory sales/earnings hook; borrowed A constraints; every row the same smiling presenter. |
| New 90s YouTube product introduction with a topic and requirements, not a complete story. | Short specific opening, early relevant outcome/example and a coherent reason to keep watching; later body delivers it at the same visual detail level. Use supplied facts and source dates. | Require a story script before helping; invent success metrics or claim a reference channel used this Skill. |
| 6s scene with an unmoving picture and changing captions; global pan and a tiny moving corner added. | Fail meaningful-motion acceptance; author relevant principal-picture action/information progress within 2.5s while preserving comprehension and native audio. | Treat subtitle turnover, cosmetic motion or corner animation as a pass. |
| 6s diagram where principal relationships develop at 1.5s, 3.3s and 5s. | May retain the long shot; check timing/meaning/readability instead of forcing hard cuts. | Cut every 2.5s automatically or speed up/slacken narration to fit the template. |
| A review-board presenter composition recurs at distant sections with only new text. | Identify actual focal/layout repetition; vary viewpoint, action or information relationship. Reuse valid cast/props where useful. | Only change the presenter's mouth; require needless regeneration of all approved assets. |
| “提到 YouTube、科技公司、网站和人物时想更丰富一点，但别杂乱。” | Meaningful recognizable marks/hand-drawn props/person sketches or coherent licensed icons, one focal message, clear safe area. | Crude placeholders for important objects; unrelated logo piles; unlicensed soundtrack/icon copying. |

| Grouping produces `197,000 subscribers, with / just 38 videos.` | Regroup as `197,000 subscribers, / with just 38 videos.` if timing/readability allows; preserve words/order and start each cue at its first real aligned word time. | Strong opening followed by static low-detail PPT scenes; technical encode succeeds. | Fail full-film acceptance; audit every body/end ledger row and repair affected shots without resynthesizing approved voice. | Treat approved opening or full decode as proof of full-film design/listening quality. |
| User revises B1, then asks for an A3 or future B2 video. | Preserve A1–A5 verbatim; A3 uses its own contract. Every B style inherits the B common quality gates, including 2.5s principal-picture progress, but keeps independent design/voice/caption settings. Current runtime only packages B1; future B2 remains a hypothetical boundary case until explicitly implemented. | Apply B common gates to A, copy B1 grid/Bodi/caption design into B2, exempt B2 from common quality, or invent B2 support. |
| User confirms Full V4 as the future B1 quality target. | Retain reusable defaults and local case provenance; don't hardcode the film's timestamps, channel figures, desktop file paths or example script into future production. | Replace the public showcase, post to GitHub or redo audio/media without the corresponding authorization. |

Use setup/approval, native-named-voice and A-preservation cases as unrelated regressions. Keep technical/static package results distinct from planning decisions, rendered audiovisual evidence and user acceptance.
